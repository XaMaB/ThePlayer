# ThePlayer identity

The mark combines a T, a play triangle and three short signal lines. Mint, blue and violet express the media path without tying the identity to a single transport.

- `logo.svg`: square icon, with a dark background; suitable for avatars and favicons.
- `mark-mono.svg`: transparent, single-color mark for print or one-color layouts.
- `banner.svg`: repository README banner.

All artwork is editable SVG. Keep the original proportions and leave clear space around the mark. Brand assets are included under the repository's Apache-2.0 license. The design has not undergone a trademark clearance search.
